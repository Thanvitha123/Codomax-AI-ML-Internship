# 🧠 Machine Learning (ML)

## What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn from data and improve their performance without being explicitly programmed.

---

## How Machine Learning Works

1. Collect data
2. Train the model
3. Test the model
4. Make predictions

---

## Types of Machine Learning

### 1. Supervised Learning
The model learns using labeled data.

**Examples:**
- Email Spam Detection
- House Price Prediction

### 2. Unsupervised Learning
The model finds patterns from unlabeled data.

**Examples:**
- Customer Segmentation
- Recommendation Systems

### 3. Reinforcement Learning
The model learns through rewards and penalties.

**Examples:**
- Self-driving Cars
- Robotics
- Game Playing AI

---

## Applications of Machine Learning

- Healthcare
- Finance
- E-commerce
- Banking
- Cybersecurity
- Social Media

---

## Advantages

- Improves accuracy over time.
- Automates data analysis.
- Identifies hidden patterns.
- Handles large amounts of data.

---

## Disadvantages

- Requires high-quality data.
- Can be computationally expensive.
- May produce biased results if trained on biased data.

---

## Conclusion

Machine Learning is one of the most important fields of Artificial Intelligence. It helps computers learn from experience and is widely used in modern applications such as recommendation systems, fraud detection, image recognition, and predictive analytics.
